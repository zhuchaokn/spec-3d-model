# 需求 — 纸样收纳筐(basket)

## 用途

存放衣服纸样的敞口收纳筐。3D 打印,FDM(Bambu P2S)。

## 外形与尺寸

- 外形 X×Y×Z = **29×20×20 cm**,敞口(顶部开放)。
- 壁厚 **3mm**,底部封闭。
- 尺寸详值见 `params.py`。

## 特征

### 1. 六边形镂空(四壁 + 底)
四面墙和底板做六边形镂空减重、透气、省料。六边形 **pointy-top(尖顶朝上)**,
FDM 竖直打印时无大面积水平悬桥。四面孔尺寸统一(孔宽 2.5cm)。孔整体落在镂空
区内、不咬边(四角留实体柱)。

### 2. 长边(X 方向前/后墙)下凹处理
前后两片长墙(29cm 边)上沿做 `\___/` 凹沿——两端满高、中间凹下,省料且便于取放:

```
____        ____
|   \      /   |
|    \____/    |
|              |
|______________|
```

### 3. 两侧把手(Y×Z 的 20×20 短墙)
左右两片短墙上,从墙顶向下 3cm 处,各做一个 **宽8×高4 cm 的胶囊状镂空**做把手。
胶囊 = 中间矩形 + 两侧半圆。

### 4. 拆分 + 卡合(打印体积约束)
P2S 打印体积 256³mm,放不下 29cm 最长边。**沿 X=0 竖切成左右两个分筐**
(BasketL / BasketR),各 ≈14.5cm 长,可分别打印。

两半在**中间的前后墙(Z 方向)**用 **C夹 + Pin** 连接:
- **左半(BasketL)= Pin**,**右半(BasketR)= C夹**;前墙、后墙各一套,共 Pin×2 / C夹×2。
- **Pin** = 圆台,底 φ5.12 / 顶 φ5.0。**从下往上滑入**(底大顶小),到底楔紧防脱。
- **C夹** = 圆环(外 φ9、内孔 φ5.12、环壁 2mm),用一个 **3mm 宽矩形 bool 减掉**、开出朝外的口 → C 形。
  竖孔轴 = Z,Pin 与 C夹孔同轴。
- 切缝附近留"禁孔带"(不打六边形孔)保留实体来承接卡合。

### 卡合定位(俯视圆心;后续 bool 的坐标依据)

以某面墙的**壁厚中心线为 0 轴**(单位 cm)。缝在 X=0,连接件落在前/后墙的缝端。以前墙为例:

- 墙厚 3mm,中心线取 0;该半缝端在墙长方向为端点。
- **L 半 Pin 圆心**:缝端墙中心线处,如 `(x=0, y=+14.5)`(前墙缝端正中)。
- **R 半 C夹圆心**:`(x=0, y=-14.5 - 0.45 + 0.2) = (0, -14.75)`。
  其中 `-0.45` = 圆心再沿墙外移一个外半径(让环内壁贴住缝),`+0.2` = 让 2mm 环壁与筐墙壁搭接相连。
- 常量见 `params.py`:`JOINT_R=0.45`、`CCLIP_OFFSET=JOINT_R-0.2=0.25`。

## 工艺约束

- 打印机 / 体积:Bambu P2S,256×256×256 mm。
- 沿 X 轴(最长 29cm)切两半。
- 卡合公差(经验值,正式拆分前先打 clip+pin 试配件定死):
  孔 φ5.12 / 柱身 φ5.0(滑配) / 柱底 φ5.12(过盈防脱);切面让位 ~0.15mm。

## 验收标准

- 成品为两件 BasketL / BasketR,各自水密(可切片打印)。
- 外形合计 29×20×20cm,壁厚 3mm。
- 六边形孔不咬边、四角有实体柱;前后墙有凹沿;左右墙有 8×4 把手。
- C夹与 Pin 同轴,能沿 Z 滑合并卡住。
