# 需求 — clip_tester(Pin/C夹 试配小件)

## 用途

打印一组 Pin + C夹 试配小件,真实对插,验证这套卡合的松紧度/公差,再定死用于 basket 等项目。
只做**一组**(一个 Pin 件 + 一个 C夹件),两个独立可打印件。

## 外形与特征

两个件,各自结构 = **一堵墙 + 一个卡合件 + 一个底座**:

- **左件(Pin 件)**:1cm(宽)× 3cm(高)的墙,墙上带 **Pin**(圆台,底 φ5.12 / 顶 φ5.0)。
- **右件(C夹件)**:同样 1×3cm 的墙,墙上带 **C夹**(墩 φ9 / 孔 φ5.12 / 3mm 开槽)。
- 卡合件高 3cm(与墙同高)。
- **底座**:每件底部一个 1mm 厚、1cm×1cm 的小底座,增大与打印板接触、防倒。
  ⚠ 底座必须**偏置**,不能挡住两件对插的通道——要能把 Pin 真实插进 C夹。

## 工艺约束

- FDM,竖直打印(墙/柱轴 = Z)。
- 公差(复用 basket 验证值):孔 φ5.12 / Pin 圆台 φ5.12→φ5.0(滑配→楔紧)/ C夹墩 φ9 / 开槽 3mm。
- 两件分开摆放,各自独立导出 STL。

## 验收标准

- 两件各自水密(边界边=0),可切片打印。
- Pin 能沿 Z 滑入 C夹孔,底座不挡对插。
- 打印后手动对插,评估松紧度。
