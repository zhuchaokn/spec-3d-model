# 导演版分镜

用户确认的六段口播保留原样，Yunxi 男声 +18%。在句子间插入观看停顿，总时长约 120 秒。只保留一键播放与结束重播。

| 章节 | 镜头安排 |
|---|---|
| 01 成品 | 高原山脉近景，低角度环绕拉远，露出完整彩色地图与底座。 |
| 02 需求 | 需求逐步展开，任务依次出现；真实轮廓承接数据。 |
| 03 数据 | 三种公开来源汇合；后段转为俯视平面模型，接下一镜头。 |
| 04 地形 | 俯视平面停留约 1 秒；约 10.5 秒逐步升高并转向 19° 低角度；完成后稳定观察，再切山脉近景横向移动；短暂展示真实 Blender 界面。 |
| 04 海洋 | 同一模型加入真实海洋面，颜色与高度渐变；镜头移向右下角南海附图，保留全部源轮廓。 |
| 04 凹槽 | 插板提起，真实国境轮廓临时填充层下沉 0.2 cm；海岸局部低角度近景与 2 mm 标记；镜头回到全图，插板嵌入。 |
| 05 拆件 | 先提起省份，再径向分开；独立观看停顿中，四片底座沿拼接方向展开，镜头升为俯视。 |
| 05 打印 | 真实拓竹九盘截图、北京试配小样、3MF / BLEND / STL 文件。 |
| 06 故事 | 制作素材组成故事窗口，最后回到同一成品模型，稳定停留后重播。 |

动画单位 cm。槽深来自 model.json 的 SLOT_DEPTH=0.2。底座尺寸、框高、四片组别与真实海洋掩膜来自现有项目数据；底座显示网格按源轮廓轻量重建。岛礁与虚线纹理保留完整源几何。动画副本不写回 Blender 或打印资产。

转场以同形地图接续、跟随对象动作及动作完成后切镜头为主；不会把拓竹截图伪装成正在执行的 UI 操作。
